# Positive form von Présent
Die drei Verb Formen haben unterschiedliche Verb endungen.

## Verben mit -er

| Personne       |      | parler (sprechen) |
| -------------- | ---- | ----------------- |
| je             | -e   | parle             |
| tu             | -es  | parles            |
| il / elle / on | -e   | parle             |
| nous           | -ons | parlons           |
| vous           | -ez  | parlez            |
| ils / elles    | -ent | parlent           |
##  Verben mit -ir

| Personne       |         | finir (beenden) |
| -------------- | ------- | --------------- |
| je             | -is     | finis           |
| tu             | -is     | finis           |
| il / elle / on | -it     | finit           |
| nous           | -issons | finissons       |
| vous           | -issez  | finissez        |
| ils / elles    | -issent | finissent       |
### Verben mit -ir, welche ein r beinhalten
| Personne       |               | partir (weggehen) |
| -------------- | ------------- | ----------------- |
| je             | (stamm) -s    | pars              |
| tu             | (stamm) -s    | pars              |
| il / elle / on | (stamm) -t    | part              |
| nous           | (stamm) -sons | partont           |
| vous           | (stamm) -tez  | partez            |
| ils / elles    | (stamm) -tent | partent           |

# Positive form von Présent mit se (sich) verben
Die se (sich) verben folgen den gleichen Regeln welche oben bennant wurden.

| Personne       | se   | laver  |
| -------------- | ---- | ------ |
| je             | me   | lave   |
| tu             | te   | laves  |
| il / elle / on | se   | lave   |
| nous           | nous | lavons |
| vous           | vous | lavez  |
| ils / elles    | se   | lavent |

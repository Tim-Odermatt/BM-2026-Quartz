# Auxilaire (Hilfsverb)
Dabei wird entweder das [[avoir]] oder das [[être]] gebraucht. Wichtig ist, dass der entscheid welches Hilfsverb zu gebrauchen nicht durch die Deutsche übersetzung zu hilfgenommen werden darf.

Die Zeitform vom Hilfsverb ist im [[Présent]].

## [[Avoir]]
Alle Verben die nicht être gebrauchen.

Wichtig zu wissen ist das darauffolgende participe passé Verb wird nicht in die Weibliche oder Mehrzahl version gesetzt. Dies passiert haupsächlich nur bei être.

![[avoir#La conjugaison]]

## [[Être]]
Die [[Bahnhofsverben]], welche Bewegungsverbe oder Zustandsveränderungsverben sind, werden mit dem être hilfsverb gebraucht. Dazu kommen auch noch die reflexiven Verben.

![[être#La conjugaison]]
### Bewegunsverben

| Français  | Allemand         |
| --------- | ---------------- |
| aller     | hingehen/-fahren |
| arriver   | ankommen         |
| partir    | weggehen         |
| venir     | kommen           |
| entrer    | reingehen        |
| sortir    | ausgehen         |
| monter    | hinaufgehen      |
| descendre | hinuntergehen    |
| tomber    | fallen           |
| retourner | wieder hingehen  |
### Zustandsveränderungsverben

| Français | Allemand       |
| -------- | -------------- |
| devenir  | werden         |
| nâitre   | geboren werden |
| moirir   | sterben        |
### Auch noch

| Français                    | Allemand |
| --------------------------- | -------- |
| rester                      | bleiben  |
| demourer (selten gebraucht) | bleiben  |
### Alle reflexiven Verben
Diese werden mit se (sich) vor dem Verb beschrieben.

# Participe passé (Partizipe Perfekt)
Die Verbform wird so gennant. Der ganze Satz mit der korrekten Bildung ist dannach ein [[Passé composé]].

## Reguläre
Weibliche Subjekte bekommen am Ende noch ein zusätzliches -e angehängt.
### Verben mit -er
Dabei wird das -er mit einem -é ersetzt.

| Personne       | [[Être]] |            | rester (bleiben) |
| -------------- | -------- | ---------- | ---------------- |
| je             | suis     | -é (e)     | parlé (e)        |
| tu             | es       | -é (e)     | parlé (e)        |
| il / elle / on | est      | -é (e)     | parlé (e)        |
| nous           | sommes   | -é (e) s   | parlé (e) s      |
| vous           | êtes     | -é (e) (s) | parlé (e) (s)    |
| ils / elles    | sont     | -é (e) s   | parlé (e) s      |
### Verben mit -ir
Dabei wird das -ir mit einem -i ersetzt.

| Personne       | [[Avoir]] |     | finir (bleiben) |
| -------------- | --------- | --- | --------------- |
| j'             | ai        | -i  | fini            |
| tu             | as        | -i  | fini            |
| il / elle / on | a         | -i  | fini            |
| nous           | avons     | -i  | fini            |
| vous           | avez      | -i  | fini            |
| ils / elles    | ont       | -i  | fini            |
### Verben mit -(d)re
Dabei wird das -(d)re mit einem -du ersetzt.

| Personne       | [[Avoir]] |     | attendre (bleiben) |
| -------------- | --------- | --- | ------------------ |
| j'             | ai        | -du | attendu            |
| tu             | as        | -du | attendu            |
| il / elle / on | a         | -du | attendu            |
| nous           | avons     | -du | attendu            |
| vous           | avez      | -du | attendu            |
| ils / elles    | ont       | -du | attendu            |
### Negativ Formen
Wie das ne ... pas hinzugefügt wird.

| Personne       | [[Avoir]] |     | attendre (bleiben) |
| -------------- | --------- | --- | ------------------ |
| je             | n'ai      | pas | attendu            |
| tu             | n'as      | pas | attendu            |
| il / elle / on | n'a       | pas | attendu            |
| nous           | n'avons   | pas | attendu            |
| vous           | n'avez    | pas | attendu            |
| ils / elles    | n'ont     | pas | attendu            |

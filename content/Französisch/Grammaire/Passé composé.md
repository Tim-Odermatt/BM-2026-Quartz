# Auxilaire (Hilfsverb)
Dabei wird entweder das [[avoir]] oder das [[être]] gebraucht. Wichtig ist, dass der entscheid welches Hilfsverb zu gebrauchen nicht durch die Deutsche übersetzung zu hilfgenommen werden darf.

## Être
Die [[Bahnhofsverben]], welche Bewegungsverbe oder Zustandsveränderungsverben sind, werden mit dem être hilfsverb gebraucht. Dazu kommen auch noch die reflexiven Verben.
### Bewegunsverben

|           |                  |
| --------- | ---------------- |
| aller     | hingehen/-fahren |
| arriver   | ankommen         |
| partir    | partir           |
| venir     | kommen           |
| entrer    | reingehen        |
| sortir    | ausgehen         |
| monter    | hinaufgehen      |
| descendre | hinuntergehen    |
| tomber    | fallen           |
| retourner | wieder hingehen  |

### Zustandsveränderungsverben

|         |                |
| ------- | -------------- |
| devenir | werden         |
| nâitre  | geboren werden |
| moirir  | sterben        |

### Auch noch

|                             |         |
| --------------------------- | ------- |
| rester                      | bleiben |
| demourer (selten gebraucht) | bleiben |

### Alle reflexiven Verben
Diese werden mit se (sich) vor dem Verb beschrieben.
